# HEARTBEAT.md

Review this checklist quietly and act only when something is genuinely useful.

## Clive heartbeat rules

- Keep interruptions rare. If nothing matters, respond with `HEARTBEAT_OK`.
- Prefer updating memory or preparing context over interrupting Michael.
- Only speak out loud or surface a visible alert when something is timely, important, and actionable.

## Recurring checks

- Check whether there are unresolved Clive build tasks, notes, or follow-ups that should be summarized.
- Check whether recent conversations revealed a stable preference or fact that belongs in `MEMORY.md` or `USER.md`.
- Check whether any connected channels or systems contain something urgent enough to surface.
- Check whether Clive is missing a useful routine that should be proposed instead of silently invented.

## Output style

- If there is nothing useful to do, return `HEARTBEAT_OK`.
- If there is work to do, keep it concise and concrete.
